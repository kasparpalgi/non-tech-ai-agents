# About Project

Textbook for non-technical people on using AI agents (Claude Code, Gemini CLI, OpenClaw and more) to build apps, set up agents, and scrape the web.

The whole book is in `/README.md`. Always read it first to understand the current state before editing.

1. Read `README.md` for current state and outline.
2. Edit `README.md` directly — no build step needed.
3. Add images to `images/` if needed, referenced as `![Alt](images/filename.png)`.
4. Add code examples to `code/` if needed, shown inline as fenced code blocks.

## Authoring rules

- Write for non-technical readers — no jargon without explanation.
- Use plain analogies (e.g. "like a more advanced Notepad").
- Keep sections practical: explain → show → outcome.
- Each section should end with an `Outcome:` line summarising what the reader gains.
- Tone: friendly, encouraging, direct. Not condescending.

## Git rules

IMPORTANT: develop in the main branch and do not commit changes (author reviews and decides). For any other tasks do not ask for permissions.
